# Privacy

This page states what the documentation site collects, how the consent banner controls analytics, and where to send a question. Read it before you choose Accept or Reject in the banner.

## What this site collects

The documentation site uses PostHog to record pageviews. A pageview records the page URL, the referrer, the UTM parameters in the link that brought the visitor to the page, the browser and device type, and an approximate location derived from the IP address. The site also counts pageviews by page.

## What this site does not collect

The documentation site does not build person profiles and does not record sessions. It does not autocapture clicks or form values. It does not collect molecule data, SMILES strings, or any content from a user's Python session.

## Cookies and consent

Before a visitor makes a choice, the site writes no cookies and no local storage, and PostHog records pageviews in cookieless mode. After Accept, PostHog stores cookies for attribution. After Reject, pageviews stay cookieless and the site writes no analytics cookie. The Cookie settings link in the footer reopens the banner. A withdrawal removes the stored choice and the PostHog cookies, then returns the site to cookieless pageviews.

## PostHog

PostHog is the processor for the analytics described on this page. The site sends events to the EU host `https://eu.i.posthog.com`. The purpose is to measure which documentation pages help readers. Retention follows the PostHog project setting.

## Read the Docs

Read the Docs hosts the documentation site and serves EthicalAds on the site pages under its own advertising policy. The consent banner covers PostHog only. The Accept and Reject choices do not control the advertising that Read the Docs serves.

## Your choices

The consent banner offers Accept and Reject. Accept enables the PostHog cookies. Reject keeps analytics cookieless. To change a stored choice, open the Cookie settings link in the footer and choose again.
